チャット同期 差分プレビュー

「同期を実行したら何が変わるか」だけを表示します（本部 / root 向け）。

🔒 dry-run のみ — このページは本番の Room・メンバー・招待を一切変更しません。 サーバーへの書き込み・一括招待は行わず、合成データ（または貼り付けたJSON）を計算するだけです。

シナリオ

自分のデータで試す（任意）

{ rooms, shops, staffs, accounts, hqMembers, events, source, previous } の形の JSON を貼り付けて「この入力で計算」。 個人情報を貼らずに済むよう、ID だけの合成データで十分に検証できます。

この画面が使っているロジック

lib/chat-rooms.js の planChatSync()（純粋関数・テスト済み: tests/chat-rooms.test.js）。 同じ計算は CLI でも確認できます: node scripts/chat-sync-demo.mjs
