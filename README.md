# 整体院経営管理ダッシュボード

整体院の経営データをビジュアル化し、パフォーマンスを分析するための総合ダッシュボードです。Google スプレッドシートと連携してリアルタイムにデータを表示します。

## ✨ 主な機能

### 📊 KPIダッシュボード
- **総売上**: 月次の個別税込売上の合計
- **総新規数**: 新規顧客の獲得数
- **平均入会率**: チーム全体の入会率
- **スタッフ平均得点**: 総合評価指標

### 📈 ランキング表示
- 個人生産性ランキング（売上ベース）
- 入会率TOP5
- 総合得点ランキング

### 🏪 店舗別分析
- 店舗別売上シェアの可視化
- 店舗ごとのパフォーマンス比較

### 💰 福利厚生管理
- 各種手当の支給状況
- 健康手当、勉強代手当、目標達成手当など
- 福利厚生項目の内訳表示

### 📋 詳細データテーブル
以下の全項目を表示：
- 基本情報（名前、院名、月）
- 新規顧客データ（新規数、入会数、入会率、単価、売上）
- 会員管理（会員数、退会数、退会率、GAP）
- 口コミ情報（Google、H、HPB）
- 売上詳細（個別税込、継続売上）
- 福利厚生・手当（20種類以上）
- パフォーマンス指標（生産性、成約率、広告費率、紹介数）
- 評価（総合得点、達成状況、達成回数）
- 残高情報

### 🔍 フィルタリング機能
- **月別フィルター**: 過去のデータを月単位で表示
- **店舗フィルター**: 特定の店舗のデータを抽出
- **検索機能**: スタッフ名や店舗名で検索

## 🚀 セットアップ

### 前提条件
- Google アカウント
- Google スプレッドシート
- Webブラウザ

### インストール手順

詳細なセットアップ手順は [SETUP.md](SETUP.md) をご覧ください。

簡単な手順：

1. **スプレッドシートの準備**
   - Google スプレッドシートを作成
   - ヘッダー行を設定
   - データを入力

2. **Google Apps Scriptのセットアップ**
   - `gas-code.gs` をApps Scriptエディタに貼り付け
   - スプレッドシートIDとシート名を設定
   - ウェブアプリとしてデプロイ

3. **フロントエンドの設定**
   - `indx.html` のGAS_API_URLを設定
   - ブラウザで開く

## 📊 データ項目

ダッシュボードは以下のデータ項目に対応しています：

### 基本情報
- 日付、名前、院名

### 新規顧客関連
- 新規数、新規入会数、入会率、新規平均単価、新規合計売上

### 会員管理
- 先月会員数、今月退会数、退会率、GAP

### 口コミ
- G口コミ、H口コミ、HPB口コミ

### 売上
- 個別税込売上、継続売上

### 福利厚生（チェック項目）
- 健康診断、フルマラソン、歯クリーニング、家族手当、イベントアクセス手当、ウェルカムファミリー手当

### 手当金額
- 健康手当、勉強代手当、誕生日手当、子供手当、目標達成手当

### パフォーマンス指標
- 個人生産性（税込）、成約率、広告費率、紹介数、タスク漏れ

### 評価
- 各セラピスト合計得点、達成/未達成、達成回数

### 残高
- 健康残高、勉強残高

## 🔄 データの更新

1. Google スプレッドシートでデータを編集
2. ダッシュボードの「再読み込み」ボタンをクリック
3. 最新のデータが反映されます

## 💡 使用例

### 月次レポートの作成
1. 対象月を選択
2. 各KPI指標を確認
3. ランキングでトップパフォーマーを確認
4. 詳細テーブルで個別スタッフのデータを分析

### 店舗別パフォーマンス分析
1. 店舗フィルターで特定の店舗を選択
2. 店舗別売上シェアを確認
3. スタッフごとの詳細データを比較

### スタッフ評価
1. 検索機能で特定のスタッフを検索
2. 総合得点と達成状況を確認
3. 福利厚生の利用状況をチェック

## 🐛 トラブルシューティング

一般的な問題と解決方法は [SETUP.md の トラブルシューティング](SETUP.md#5-トラブルシューティング) をご覧ください。

### よくある問題

**Q: データが表示されない**
- GAS_API_URLが正しく設定されているか確認
- スプレッドシートIDとシート名が正しいか確認
- ヘッダー名が正確に入力されているか確認

**Q: エラーメッセージが表示される**
- ブラウザの開発者ツール（F12）でコンソールを確認
- GASの実行ログを確認
- 権限が正しく設定されているか確認

## 📝 カスタマイズ

### 新しいKPI指標の追加
`indx.html` の `stats` 計算部分を編集してください。

### デザインの変更
Tailwind CSSクラスを編集してカスタマイズできます。

### データ項目の追加
1. スプレッドシートに新しい列を追加
2. `gas-code.gs` の `formatRowData` 関数に項目を追加
3. `indx.html` で新しい項目を表示

## 🔒 セキュリティ

- デフォルト設定では、デプロイしたGAS APIは「全員」がアクセス可能です
- より厳密な認証が必要な場合は、GASのアクセス設定を「自分のみ」に変更してください
- 機密情報を含むデータを扱う場合は、適切なアクセス制御を実装してください
